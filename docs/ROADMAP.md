# 개발 로드맵

## 범위

로봇 팔 한 대, 블록 하나, 집기 작업 하나, ACT 모델 하나로 시작합니다. 첫 학습·평가 결과를 완성한 뒤 서빙과 ROS 2 작업 관리를 추가합니다.

## 1주차: 실행 환경과 시연

- [x] 기존 Python 환경과 GPU 확인, 프로젝트 전용 Python 3.12 환경 준비
- [ ] Linux/WSL 사용 가능 여부 확인 (ROS 2 연동 단계에서 진행)
- [x] 패키지 버전과 현재 PC 실행 명령 기록
- [x] MuJoCo 물리·RGB 렌더링과 Panda 집기 환경 초기화·한 단계 실행
- [ ] 키보드 또는 컨트롤러로 시연 에피소드 하나 저장
- [ ] 관측값과 행동 텐서의 형태 확인

완료 기준: 직접 조작하는 영상과 재실행 가능한 명령이 남아 있습니다.

## 2–3주차: 데이터와 첫 학습

- [ ] 시연 데이터 수집 및 실패한 시연 검토
- [ ] 이미지·상태·행동 데이터의 대응 관계 확인
- [ ] 학습용과 검증용 데이터를 에피소드 단위로 분리
- [ ] 작은 배치로 ACT 학습 및 GPU 메모리 사용량 확인
- [ ] 체크포인트 저장·불러오기와 시뮬레이션 추론 확인

완료 기준: 첫 모델의 실행 영상과 학습 설정이 남아 있습니다. 성공률이 낮아도 결과를 그대로 기록합니다.

## 4–5주차: 평가와 비교 실험

- [ ] 시연 데이터 양을 달리한 두 설정 비교 (예: 10개 / 30개)
- [ ] 학습에 사용하지 않은 초기 위치와 고정된 평가 시드 준비
- [ ] 성공 판정 기준과 시간 제한 정의
- [ ] 성공 횟수 / 전체 시도 수, 작업 시간과 실패 원인 기록
- [ ] 실패 유형 하나를 분석하고 개선 전후 비교

완료 기준: 동일한 평가 조건에서 비교한 결과표와 실패 영상이 남아 있습니다.

## 6주차: 추론 서비스

- [ ] 모델 실행과 시뮬레이터 실행을 별도 프로세스로 분리
- [ ] 관측 입력·행동 출력 인터페이스 정의
- [ ] 모델 버전과 전처리 설정 기록
- [ ] 추론 지연 및 통신 오류 기록
- [ ] 직접 실행 방식과 서비스 방식의 작업 결과 비교

완료 기준: 실제 모델 추론 결과가 시뮬레이터 동작에 사용되고, 지연 측정 결과가 남아 있습니다.

## 7주차: ROS 2 작업 관리

- [ ] 작업 시작·진행 상태·완료 결과 인터페이스 정의
- [ ] 시뮬레이터를 연결하는 어댑터 구현
- [ ] 취소와 시간 초과 처리
- [ ] 취소 뒤 행동 실행이 멈추는지 확인

완료 기준: ROS 2를 통한 실제 시뮬레이션 작업 실행과 상태 확인이 가능합니다. 시뮬레이터 연동은 별도 구현 항목이며 자동 연결을 가정하지 않습니다.

## 8주차: 통합 확인과 정리

- [ ] 정상 완료·실패·취소·시간 초과 시나리오 확인
- [ ] 설치 및 실행 문서 업데이트
- [ ] 짧은 데모 영상과 실험 결과표 정리
- [ ] 구현 범위와 남은 한계 명시

## 진행 기록

2026-10-04: Windows Python 환경 구성. 의존성 포함 Python 패키지 178개 설치, CUDA 계산·역전파와 시뮬레이션·영상 검사 18개 통과. 자세한 내용은 [환경 설정](SETUP.md)과 [학습 가이드 PDF](../output/pdf/robot_learning_environment_guide_ko.pdf)에 기록했습니다. 시연 저장과 ACT 학습은 아직 수행하지 않았습니다.

각 실험은 데이터 구성, 코드 커밋, 패키지 버전, 학습 설정, 평가 시드, 성공 횟수와 실패 원인을 함께 기록합니다.

환경 설정이 길어지면 같은 환경·관측·행동 형식에 맞는 공개 데이터 활용 가능성을 검토합니다. 일정은 실제 재현 결과를 기준으로 조정합니다.
